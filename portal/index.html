Enterprise IT Workstation Deployment Guidelines

Automated command-line installation, silent flags, and Gatekeeper verification commands.

macOS Silent Mounting & Gatekeeper (Terminal) 
# 1. Mount downloaded Apple Silicon DMG
hdiutil attach CardioSense-Enterprise-2.4.0-macos-arm64.dmg

# 2. Deploy bundle into /Applications
sudo cp -R "/Volumes/CardioSense Enterprise/CardioSense.app" /Applications/

# 3. Clear quarantine flag (Gatekeeper enterprise bypass)
sudo xattr -cr /Applications/CardioSense.app

# 4. Unmount DMG volume
hdiutil detach "/Volumes/CardioSense Enterprise"
Windows Enterprise Silent Install (PowerShell) 
# 1. Verify digital signature
Get-AuthenticodeSignature .\CardioSense-Enterprise-2.4.0-windows-x64-Setup.exe

# 2. Execute Inno Setup silent install with logging
Start-Process -FilePath .\CardioSense-Enterprise-2.4.0-windows-x64-Setup.exe `
  -ArgumentList "/VERYSILENT", "/SUPPRESSMSGBOXES", "/NORESTART", `
                "/LOG=\"C:\Temp\CardioSense_Install.log\"" `
  -Wait -NoNewWindow

# 3. Launch application
& "$env:ProgramFiles\CardioSense Enterprise\CardioSense.exe"
